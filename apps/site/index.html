DSH 插件

dsh-plugin-space

在 DSH 对话里引用文档、审阅建议、处理评论。

  1. 打开 DSH 左侧 Plugins，点 Add plugin。
  2. 输入 dsh-plugin-space 并确认安装，然后启用。
  3. 从左侧栏进入 CoSpace。
dsh plugin add dsh-plugin-space

需要 DSH 0.2.3-alpha.2 及以上 · Node.js 24+

想从市场发现：在 Experimental plugins 开启 Custom plugin indexes，再添加索引源↗。

其他 Agent

WorkBuddy 等 stdio MCP 客户端

先安装桌面端，再由桌面应用写入 MCP 配置并安装文档协作 Skill。

  1. 按上方说明安装并打开 CoSpace Desktop。
  2. 在应用内选择接入 WorkBuddy，自动写入 MCP 条目。
  3. 重新连接 Agent，在新会话确认 CoSpace 工具可用。

接入会保留其他 MCP 条目；同名配置无法确认归属时会停止并提示检查。移动或卸载应用后需重新接入。

工作方式

  1. 01

    选择文档

    新建一份文档，或选择你想继续完善的内容。

  2. 02

    提出建议

    告诉 Agent 你的想法，也可以在文档里留下评论。

  3. 03

    由你决定

    逐条查看修改，接受你认可的内容，其余保持原样。

文档与审阅记录保存在本机 SQLite。DSH 插件与桌面端各自使用独立的数据目录。

CoSpace 把文档，留在自己的掌控中。
