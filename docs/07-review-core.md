# 07 · Markdown 文本审阅内核

正文以 Markdown 源字符串存储。创建时保留原始字符串；读接口通过 `content` 返回 Markdown 文本、正文版本和建议。建议是独立 SQLite 记录：基准版本、UTF-16 左闭右开坐标、预期原文、替换文本、上下文、创建顺序、建议人和创建时间。新增、删除、修改统一表示为文本替换。建议不直接改变正文，只有用户接受才应用。

提交在 SQLite `BEGIN IMMEDIATE` 事务内校验版本、代理对边界、预期原文和重叠。不同范围的建议可并存；同一位置插入按创建顺序排序；插入在修改范围端点归属范围外侧，范围内部插入和真正重叠返回冲突。接受正文后根据变更历史映射其他建议及评论；映射后必须再次校验预期原文。不能安全定位的建议保留并标记冲突。拒绝关闭建议而不改变正文版本。操作 ID 幂等。

无架构标记的旧数据库仍按既有规则重建；`markdown-text-v1` 数据库通过新增字段迁移为 `markdown-text-v2`，保留文档、建议和评论。旧建议的建议人记为 Agent；因旧数据没有创建时间，界面显示时间未知。新建议会保存准确创建时间。评论锚点直接使用 Markdown 字符串坐标；渲染预览选区与源码区选区都映射为 UTF-16 偏移。待处理建议在渲染后的正文中以内联删除线和新增文字呈现，右侧卡片只提供建议人、时间及决策按钮。Markdown 预览关闭原始 HTML。

验证入口：`npm run build:client`、`npm run check` 和 `sh scripts/test-ui.sh`。完整宿主端到端流程仍需在目标 DSH 环境验收。
