# 01 · 领域模型与一致性

Space 保存 Markdown 源文本作为文档事实源。文档包含稳定 ID、正文版本和 Markdown 字符串；建议独立存储为文本替换，包含基准版本、UTF-16 左闭右开范围、预期原文、替换文本和上下文。评论锚定到 Markdown 源文本范围。渲染只用于阅读，不参与存储或坐标计算。

Agent 可创建完整初始正文，创建后只能提交建议；只有用户能接受或拒绝建议。评论只在用户显式操作时发送。正文版本在接受替换时递增；建议提交和决策由事务串行化，操作 ID 幂等。

同一插入点的建议按创建序号稳定排列；边界插入分别位于目标范围外侧；内部插入及真正重叠拒绝并返回冲突。接受建议时通过变更历史映射其他锚点，原文校验或映射无法确认时保留建议并标为冲突，不猜测、不静默改写。

Markdown 方言和预览能力由渲染器决定；保存源文本不会损失渲染器不支持的语法。现有旧格式数据库可在启动时删除并重新初始化，不执行隐式内容转换。
