# 15 · Agent 风格偏好

风格偏好独立于 Markdown 文档正文。用户可在首页设置全局风格偏好，也可在文档页面为当前文档单独设置；输入后自动保存。MCP 读取偏好并提供给 Agent，不写入文档正文。正文版本、评论锚点和建议状态不随偏好变化。

偏好用于记录受众、语气、术语、格式和表达习惯。当前任务中的明确要求优先于长期偏好；偏好不能扩大评论处理或建议决策的授权。Agent 仍通过建议与用户协作修改文档，只有用户决定接受或拒绝建议。

全局与文档偏好保存在宿主各自的 `review.sqlite`，保持宿主数据隔离。删除文档时，文档级偏好与审阅数据在同一事务中删除；全局偏好保留。旧的 `collaboration.sqlite` 不会自动迁移。
